Website Upload Manual

Use this page when you need to upload or update data for the website from the live site or hosted server.

1. Prepare your content

Gather the text, images, files, and links you want to publish. Make sure images are sized appropriately and have descriptive names.

2. Locate the upload interface

If your site is hosted on a content management system (CMS), server control panel, or hosting dashboard, open the upload area there. Common systems include GitHub Pages, FTP/SFTP, cPanel, or a website builder.

3. Upload files

Upload HTML, CSS, JavaScript, or image files to the website's document root or the folder where your site files reside. If the upload interface has a drag-and-drop area, use that for image files.

4. Edit page content

Open the page editor or HTML file in the hosting dashboard and update the content directly. For example, update paragraphs inside section tags or replace image source paths.

5. Update navigation links

Ensure the navigation links point to valid pages or section anchors. For example, use index.html#about_us for the About section on the home page.

6. Save and publish

After making changes, save the page or upload. Use the publish/deploy button if the hosting platform requires it to make changes live.

7. Verify on the live site

Open the website in a browser and refresh the page to confirm your update is visible. Clear cache if needed.

8. Helpful reminders

  • Use descriptive alt text for images.
  • Keep file names simple and lowercase with hyphens.
  • Back up existing content before making major changes.
  • If you have access to version control, commit and push updates instead of overwriting files directly.
